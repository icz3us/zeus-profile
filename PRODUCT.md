# Zeus portfolio

Personal portfolio for Zeus, a web developer and designer based in Manila, Philippines. Visitors explore real projects, understand his technical skills, experiment with ASCII art, and get in touch about projects or roles.

Preserve existing biography, availability, skills, all project descriptions and case-study details, repository and live-site links, social links, email copying, project dialogs, and mobile navigation. The user requested removing the separate Playground section, redundant text, CRT functionality, and all sound functionality. Keep interactive ASCII artwork in the hero; place the introductory description directly below the developer/designer title. Use compact section spacing and omit repeated slogans and profile facts. Do not invent experience, performance metrics, clients, or project screenshots.

Stack: Next.js App Router, React, TypeScript, Tailwind CSS, GSAP, Lenis. The user approved a paper-white, experimental editorial redesign inspired by their green-and-paper print-study reference. Accessibility, mobile usability, reduced motion, and efficient animation are requirements.
